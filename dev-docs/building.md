# Building aloud for Desktop

The desktop app is built with **Tauri 2**. See **[desktop.md](desktop.md)** for
the full build, signing, and release flow (`cd ts && npm run tauri:build`),
prerequisites, and the endpoint list.

> The original PyInstaller-based Python build was removed in meditation-pal-sk8.
> If you followed an old link here for `aloud.spec` / `uv pip install
> pyinstaller`, that path no longer exists — use Tauri.
