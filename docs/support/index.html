It can't hear me

aloud is voice only, so it needs the microphone.

  • iPhone and iPad: Settings → aloud, allow Microphone and Speech Recognition.
  • Android: Settings → Apps → aloud → Permissions → Microphone.
  • Browser: allow the microphone for aloud.rest when asked, or from the site settings next to the address bar.
